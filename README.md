# MATRIX ESCAPE

You are **Kat**. The grid is trying to recapture you.

Single-file HTML5 arena shooter. Open `index.html` in a browser, or play on GitHub Pages.

**Play:** https://twiztid4200.github.io/Matrix-Escape/

## Controls

- Desktop: `A/D` move · `W` / Space jump · `J` shoot · `Shift` dash · `K` breach · `Esc` pause
- Phone: stick left, JUMP / SHOOT / DASH / BREACH right
- Combo feeds **Trace**. Trace feeds the system. **Breach** costs Trace and buys silence.
- Fork cards at 30s / 90s / Sentinel down. Floor packets are juice. Permanents come from Couriers, Sentinels, and cards.

## Local

Open `index.html`. No build step.
